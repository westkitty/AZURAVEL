## Concrete validation

- **111/111 local automated tests passed**: 80 original Python reference and specification tests plus 31 new browser and regression tests; source: `evidence/all_tests.log`.
- Exactly **100 canonical roots and 600 valid derived forms** retained; all 600 new JavaScript transformations and payload round-trips validated.
- Original governing files remained identical to original release: `AZURAVEL_DATA.json`, `AZURAVEL_SPEC.md`, `azuravel_ref.py`, `test_azuravel.py`; check `PROTECTED_HASHES.json`.
- All **20 original analyzed sentences** remain valid.
- **Five SVG barcode instances** generated by the browser were rasterized and read with an independent pyzbar/zbar optical decoder; correct Code 128 payloads returned. This is not a hardware camera or printer validation.
- The old atlas extended beyond a 320px viewport; the new atlas did not overflow on any of six sections at 320, 360, 390, 768, 1024 and 1440 CSS pixels.
- Loom inverse, reset, cross-root history, live diagram, keyboard, 12-trial practice, errors, no-storage operation, deep-link route, inter-station handoffs, and explicit audit passed functional browser tests.
- Clean-room build reproduces standalone HTML **byte-for-byte** from packaged sources. No network/CDN/external runtime dependency introduced.

## Evidence boundaries and adversarial re-scoring

- Chromium in this execution sandbox blocks direct `file://` page navigation; the browser tests loaded the **actual HTML bytes** into a document using Playwright. Thus true double-click file-origin behavior is **UNVERIFIED**, not passed by inference.
- Persistence read/write and restoration were verified with a simulated/local storage object; native browser `file://` storage is **UNVERIFIED** and the interface degrades gracefully if unavailable.
- Real touch input hardware, screen-reader announcement behavior, physical barcode scanning/printing, long-session battery/fps/memory, production CDN/service worker, and real-host deployment were **not tested**.
- Architecture is still an original large front-end script plus an extension. This is a bounded uplift, not a modular framework rewrite; code complexity has not magically vanished.
- Some 4/4 scores indicate exceptional integration **only within tested scope**. Experience and art-direction judgments should be challenged with outside user trials rather than inferred universally.
- The 85+ aspiration was **not achieved by evidence**. Accepting 80 is more honest than assigning five unearned points.
